# Security reporting

Please do not post credentials, account takeover steps involving real users or private personal data in public issues. Contact the project maintainers through [Questio Discord](https://discord.gg/27jXU6C4Qg) to arrange a private report. GitHub private vulnerability reporting can also be used if the repository owner has enabled it.

State the affected app version, the impact and a minimal reproduction using test data. A local diagnostic report is optional and should be reviewed first. No private token is required to demonstrate an ordinary app bug.

Only the latest published release is the target for new fixes. No formal security SLA is offered. The local membership and owner phrase controls are not an unbreakable licensing boundary; a user controlling the PC can inspect or modify the executable.

# Support

Use the GitHub bug form for reproducible app problems, or join [Questio Discord](https://discord.gg/ERzQaHgPeV).

Include app version, Windows version, exact steps and what happened. Separate the app's local timer from progress shown in Discord. Do not post passwords, OAuth tokens, session.dpapi, owner-workspace.dpapi or an AppData archive.

Settings → Export diagnostics creates a small JSON file on your PC. It includes app/Windows/runtime versions, language, session counts and boolean access status only. Review it before attaching it. It does not contain your account identity, game history, local file paths or raw exceptions, and it is never uploaded automatically.

For failed sign-in, check your network and retry through the official Discord browser window. A nonmember must accept the invite and any server rules, then choose Check membership. Revoked authorization requires a fresh sign-in. Rate limiting requires waiting before retrying.

For a damaged settings file, close Questio and back up your local data before changing anything. Never delete your Steam game folders to troubleshoot Questio. The optional FC 27 setup has its own owned-file removal action and is experimental.

The project does not promise Discord rewards or a response-time SLA. See KNOWN_ISSUES.md before filing a duplicate.
